# AGENTS.md — game 공통 하네스

`D:/game` 아래 게임들이 함께 쓰는 하네스다. 게임마다 `D:/game/<게임>/`에 따로 git 저장소와 AGENTS.md를 둔다. 게임 폴더에서 세션을 열면 이 파일과 그 게임의 AGENTS.md가 함께 로드된다.
응답·문서는 한국어. 코드·식별자·경로·명령·에러 메시지는 원문 그대로.

## 지금 어디에 있나

공통 하네스 레벨 1 구축(2026-10-25, 설계 `docs/specs/2026-10-25-common-harness-design.md`). 등록된 게임: `hsl`(2026-10-25 `D:/hsl`에서 옮겨 연결), `proxywar`(2026-10-27 `tools/new-game.sh`로 생성).

## 어디에 무엇이 있나

- `harness/` — 자기개선 루프와 범위 판정 기준(`README.md`), 공통 교훈 색인(`LESSONS.md`, G-NNN), 공통 라이브러리
- `.claude/skills/harness-reflect/`, `.claude/agents/harness-*.md` — 루프. 게임 폴더에는 정션으로 연결된다
- `tools/` — `new-game.sh`(새 게임), `link-common.sh`(공통 스킬·서브에이전트 정션), `harness-tool-log.sh`(도구 로그 훅)
- `templates/game/` — 새 게임 하네스 틀
- `docs/specs/` — 공통 하네스 설계서. `docs/archive/reports/` — `design-report` 스킬이 만드는 HTML 보고서

## 작업 방식

- 게임 작업은 그 게임 폴더에서 세션을 연다. 새 게임은 `bash tools/new-game.sh <이름>`으로 만든다.
- 과제가 끝나면 `harness-reflect`로 돌아본다. 편집마다 범위를 정한다: 이 게임 하네스만 / 공통 하네스. 기준은 `harness/README.md`.
- 질문 선택지와 설계 절의 전제는 그 게임 AGENTS.md가 가리키는 확정 결정 기록(결정 로그·ADR)에 있는 것뿐이다. 상위 설계서의 분해·범위 문구(슬라이스 표의 개수·목록 같은)나 에이전트가 먼저 정한 구조(공격 버튼 하나 같은)·수치(선택지 설명에 넣은 "매치당 3회쯤" 같은 예시)는 확정이 아니므로 — 사용자가 그 선택지를 골랐어도 예시 수치는 미정이다 — 그것으로 선택지를 좁히거나 절을 쓰기 전에 묻는다. <!-- G-007 -->

## 하지 않는 것

- 요청 없이 `git commit`·`git push`·브랜치 조작.
- 게임 작업 중에 공통 하네스(이 폴더의 AGENTS.md·`.claude/`·`tools/`·`templates/`·`harness/`)나 다른 게임 폴더를 고치기. 공통 변경은 `harness-reflect` 6단계 승인이나 사용자의 직접 요청으로만 한다.
- 승인 없이 외부 에셋·라이브러리 다운로드. 승인 뒤의 설치·다운로드·실행은 사용자에게 넘기지 않고 에이전트가 한다 — 설계서·계획에 "사용자 실행"을 두지 않는다. UAC·샌드박스에 막히면 우회(사용자 폴더 설치, 샌드박스 해제 재시도)를 먼저 한다. <!-- G-004 -->
- 계획·설계서·다음 단계 제안에 외부 전제(릴리스 자산 이름, 다운로드 크기, 설치 경로·방법, 외부 서비스의 이용 수단·비용)를 확인 없이 "있을 것"으로 적기. 실행 전에 한 번 실제로 조회(API·HEAD)하고 근거를 적는다. 못 확인한 것은 "미확인"으로 표기한다. <!-- G-005 -->
- 검증 출력을 읽지 않고 완료·커밋으로 넘기기. 서브에이전트에 요구하는 "확인 출력을 보이라"는 규율은 직접 한 수정에도 같다. <!-- G-006 -->
- 사용자가 채워 넣어야 완성되는 질문·버튼 메시지. 그대로 눌러도(답해도) 완결된 답이 되게 쓴다. <!-- G-001 -->

## 환경 메모

- 홈 디렉터리(`C:/Users/roehf`)에 별개의 git 저장소가 있다. git 명령은 게임 폴더(게임 저장소) 또는 `D:/game`(공통 저장소) 안에서만, 어느 저장소인지 확인하고 실행한다. 공통 저장소는 게임 폴더를 `.gitignore`로 뺀다.
- `CLAUDE.md`는 두지 않는다. Claude Code 2.1.277+는 `AGENTS.md`를 자동 로드하고, 상위 폴더의 `AGENTS.md`도 함께 로드한다(2.1.291, 2026-10-25 확인). <!-- G-002 -->
- 상위 폴더의 `.claude/`(스킬·서브에이전트·`settings.json` 훅)는 게임 세션에 로드되지 않는다(2026-10-25 실측). 그래서 공통 스킬은 게임의 `.claude/skills/<스킬>`, 서브에이전트는 `.claude/agents/_common` 정션으로 연결하고, 훅은 게임 `settings.json`이 `../tools/`를 부른다. 게임 세션에 `harness-reflect`가 안 보이면 `bash ../tools/link-common.sh <게임>`.

이 문서는 공통 기본 하네스다. 모든 게임의 모든 과제에 해당하는 규칙만 두고, 출처 항목을 `<!-- G-NNN -->` 주석으로 단다. 게임 고유 규칙은 그 게임의 AGENTS.md로, 과제별 교훈은 라이브러리로 보낸다.
